#go_concurrency_practice

Небольшой учебный проект для практики конкурентности в Go.  
Собран из нескольких примеров, чтобы закрепить работу с goroutines, channels, context, waitgroup, mutex и atomic.

## Структура проекта

## Описание

---

### Miner Pool

Пакет `miner` реализует пул «шахтёров»:

- несколько goroutine работают параллельно
- каждая имитирует добычу ресурса
- данные передаются через канал
- остановка происходит по `context.Context`
- используется `WaitGroup` для корректного завершения
- канал закрывается после завершения всех workers

---

### Postman Pool

Пакет `postman` реализует пул «почтальонов»:

- несколько goroutine доставляют письма
- каждая отправка — отдельная операция
- данные передаются через канал
- остановка по context
- корректное завершение через `WaitGroup`

---

### main.go

В `main`:

- создаются отдельные контексты для шахтёров и почтальонов
- управление временем работы через `context.WithCancel`
- сбор результатов:
  - сумма добытого ресурса через `atomic`
  - список писем с защитой через `mutex`
- ожидание завершения всех обработчиков через `WaitGroup`

Используемые инструменты:
- `context`
- `sync.WaitGroup`
- `sync.Mutex`
- `sync/atomic`
- каналы и goroutines

---

## Цели проекта

- закрепить работу с конкурентностью в Go
- понять жизненный цикл goroutines
- научиться правильно закрывать каналы
- безопасная работа с общими данными
